Use your own Atlas key

Your key stays in this tab and goes only to api.mothquantum.com. Atlas only accepts browser calls from localhost, so the deployed site forwards otoc-echo-v1 requests through its own /api/atlas proxy. Without a key, the proxy lends the site's key for 12-qubit emulator runs, a few per visitor per hour, and that key never reaches your browser.
