Runs otoc-echo-v1 (aer emulator, exact, depth 32, 1 credit) with your own Atlas key. The key stays in this tab and is sent only to api.mothquantum.com.

How the browser reaches Atlas

Atlas's CORS policy only admits http://localhost:3000. Running locally (npm run dev), the page calls the API directly. On a deployed site it goes through a small same-origin proxy (/api/atlas) that forwards only otoc-echo-v1 submit/status/result calls with your key. If the site owner has enabled it, the proxy can also lend its own key when you leave the field empty: only for small emulator runs (12 qubits, depth 32, aer, exact), a few per visitor per hour and a daily cap, and the key never reaches your browser. On a static host without the proxy, the explorer runs on the measured runs only.
